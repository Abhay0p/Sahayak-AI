# Changelog

All notable changes to the Sahayak AI project will be documented in this file.

## [1.0.0-rc.1] - 2026-09-11
### Added
- **Elderly Portal**: Completed the "My Day / Care Timeline" with priority engine (SOS/Overdue/Current/Upcoming).
- **Voice Assistant**: Gemini 1.5 Flash integration with 6 new timeline-specific intents.
- **Multilingual Architecture**: Supported routing of languages through Next.js contexts, translating AI responses and TTS.
- **Family Portal**: Patient overview, messaging, family memories integration.
- **Caregiver/Healthcare Portals**: Dashboards for managing patients, care tasks, and clinical details.
- **Cognitive Games**: Deployed 13 specific cognitive activities with offline PWA support capability.

### Fixed
- Replaced hardcoded hydration values with real backend integration (`/notifications/hydration`).
- Standardized the GitHub repository structure for Smart India Hackathon (SIH) 2026 evaluations.
- Added comprehensive documentation (`docs/` directory).
