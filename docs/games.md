# Cognitive Games Catalogue

Sahayak AI includes a suite of 13 cognitive games and activities designed specifically for elderly users. These activities focus on memory retention, pattern recognition, spatial awareness, and cognitive engagement in a stress-free environment.

**Clinical Disclaimer**: These games are designed for engagement and cognitive stimulation. They are not diagnostic tools and do not constitute medical treatment.

## 1. Memory Match
- **Objective**: Flip cards to find matching pairs.
- **Cognitive Target**: Short-term memory and visual recognition.
- **Features**: Progressive difficulty, visually distinct high-contrast icons.

## 2. Memory Recall
- **Objective**: Memorize a sequence or list of items, then recall them.
- **Cognitive Target**: Working memory and retention.

## 3. Spot the Difference
- **Objective**: Compare two similar images and identify the discrepancies.
- **Cognitive Target**: Attention to detail, visual scanning, and spatial memory.

## 4. Pattern Detective
- **Objective**: Identify the next logical item in a visual or logical sequence.
- **Cognitive Target**: Logical reasoning and pattern recognition.

## 5. Market Memory
- **Objective**: Memorize a shopping list and "purchase" the correct items from a virtual store.
- **Cognitive Target**: Practical daily-life memory and categorization.

## 6. Pack the Bag
- **Objective**: Remember which items were packed into a suitcase.
- **Cognitive Target**: Spatial memory and sequential recall.

## 7. Remember the Place
- **Objective**: Recall the specific locations of objects in a room or grid after they are hidden.
- **Cognitive Target**: Spatial memory and object permanence.

## 8. Sequence Master (Simon Says)
- **Objective**: Repeat a growing sequence of colors/sounds.
- **Cognitive Target**: Auditory/visual working memory and concentration.

## 9. What's Missing?
- **Objective**: View a set of objects, close eyes, and identify which object was removed.
- **Cognitive Target**: Visual memory and deductive reasoning.

## 10. Family Memory
- **Objective**: Identify family members by name, face, or relation.
- **Cognitive Target**: Long-term memory, personal connection, emotional engagement.
- **Note**: Integrates directly with the `Memories` photo album uploaded by the Family portal.

## 11. Music Memory
- **Objective**: Recognize familiar tunes, instruments, or match sound patterns.
- **Cognitive Target**: Auditory memory and emotional recall.

## 12. Memory Challenge
- **Objective**: A daily mix of quick, varied memory tasks.
- **Cognitive Target**: Overall cognitive agility.

## 13. Story Time
- **Objective**: Read or listen to a short story, then answer simple comprehension/memory questions.
- **Cognitive Target**: Reading comprehension and narrative memory.

## Bonus: Breathing Exercise
- **Objective**: A guided, visual deep-breathing exercise.
- **Cognitive Target**: Relaxation, anxiety reduction, and mindfulness.

---

### Design Philosophy
- **Failure-Free Framing**: There is no "Game Over" or harsh penalty.
- **Adaptive Difficulty**: Games adjust based on the user's success rate to avoid frustration.
- **High Contrast**: Large text, clear icons, and accessible colors for aging eyes.
